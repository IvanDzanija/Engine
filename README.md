# Engine

This repository contains laboratory exercises and supporting code for the FER
**Interatactive Computer Graphics** course.

## Description

The project is a C++23 and CMake codebase. It uses OpenGL together with GLFW and
Assimp for rendering, window management, input, and model loading.

## Laboratory Exercises

The labs cover the graphics pipeline from basic shader rendering to more
advanced topics such as model loading, scene handling, culling, texturing,
curves, and shadows.

## Build

```bash
./build.sh
```

Each lab is built as a separate executable under `build_debug/LabXX`.
